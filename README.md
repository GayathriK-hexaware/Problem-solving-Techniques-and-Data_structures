This repository contains the assignments and coding exercises completed as part of the Problem Solving and Data Structures training.

The assignments cover the following topics:

Algorithm Basics

Data Structures Basics

Sorting Techniques

Searching Techniques

Trees

Hashing and HashMaps

Graphs

Two-Pointer and Sliding Window Patterns


The assignments are implemented using Python and are based on simple real-world scenarios to practise problem-solving skills and understand data structures and algorithms.
